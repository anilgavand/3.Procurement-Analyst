# 3.Procurement-Analyst
Procurement Analyst is a professional who analyzes purchasing data, supplier performance, spending patterns, and procurement processes to help an organization reduce costs, improve efficiency, and make better sourcing decisions.
<br>
Key Responsibilities:
<br>
1. Analyze purchasing and spend data
2. Monitor supplier performance and KPIs
3. Identify cost-saving opportunities
4. Support sourcing and contract negotiations
5. Track inventory and procurement trends
6. Create procurement dashboards and reports
7. Ensure compliance with procurement policies
8. Forecast demand and procurement requirements
